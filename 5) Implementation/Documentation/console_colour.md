# Console Colour Header File

##

### This will give a brief on the C and header file

By using the function in the code we can assign different colour into our console.

By specifying header file and calling function we can assign colour.

The function call are as follows:

- white_console();
- red_console();
- green_console();
- blue_console();
- yellow_console();
- cyan_console();
- pink_console();
- black_console();
