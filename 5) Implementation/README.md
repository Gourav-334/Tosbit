## Directory Structure (Description)
### Description:
- **Application Setups:** Contains *setups* for various versions of *"Data Godown"*.
- **Source Code:** Contains all the files *required for collaborating developers* to understand the project.
- **.git:** Contains the *version control* information about the project.
- **1\) Objectives:** Stores markdown files with written information about the *objectives* set for various *"Data Godown"* versions.
- **2\) User Design:** Information about the *expected design* of the end product for a particular version.
- **3\) Logic Planning:** Contains logic behind concepts & codes used in various versions.
- **4\) Flowcharts:** Contains *flowcharts* made for concepts & codes used in various versions.
- **5\) Pseudo Code:** Contains *pseudo codes* for the codes later programmed.
- **6\) Actual Code:** Are the *final codes* formed.
- **7\) Deployment:** Contains the *final version components* in conventional format. These are the files that developers can collaborate to.
- **8\) Feedback & Addition:** Files here contain the *new requirements* as per feedback or necessities to be added in next batch.

### Things to note:
- Setups in ***Application Setups*** are using [NSIS](https://nsis.sourceforge.io/License) packaging.
- ***Application Setups*** contains files meant for end users, which might not be much helpful to the collaborating developers.
- ***Source Code*** contains files meants for collaborating developers.
- Flowcharts in folder ***Flowcharts*** are made from [ClickCharts Diagram and Flowchart Software](https://www.microsoft.com/store/productId/9P4Z613MQRFR?ocid=pdpshare) by [NCH Software](https://www.nchsoftware.com/chart/index.html), which might not open from any other software.
- All codes are written using [GCC compilers](https://gcc.gnu.org/onlinedocs/libstdc++/manual/license.html).
- The directory arrangement of the project is such because it uses a *custom SDLC* (Software development life cycle).
