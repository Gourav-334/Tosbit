# $docs/$


- `algo/` - Contains algorithms for all functions in each source file (named by name of source files).
- `charts/` - Contains flowcharts & Deterministic Finite Automata diagrams.
- `contribution/` - Contains prerequisites & contribution guidelines for all level of developers.
- `legacy/` - Contains some legacy files, which are not being used anymore.
- `plan/` - Contains planning for future implementations.
- `represent/` - Contains some representations like database hierarchy or regular expressions.
