## 2. Terminologies

- **<u>String restrictions</u>:** Restrictions on `STRING` data type in ***Tosbit*** which can block security vulnerabilities.
- **<u>Cleansing deleted</u>:** Caching & putting back only undeleted data to file (for storage & searching).
