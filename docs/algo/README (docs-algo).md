# $docs/algo/$


- `database_operations.md` - Contains functions written to run various **operations** on the database. Also includes some **secondary DFA** parsers.
- `driver_manager.md` - Contains socket code documentation for connecting to a remote server or even local one through C programs.
- `encrypter.md` - Notes for applying simple encryption when storing sensitive data & also decrypts when retrieving them.
- `engine.md` - Central program to assemble rest of the components on it & run the final executable.
- `profile_manager.md` - Manages entered user credentials & verification of it.
- `queue.md` - Provides interface to make object-styled structure instances for queues.
- `server.md` - Contains socket codes for server to handle client request & execute its commands.
- `shell_piping.md` - Contains functions which retrieve information from shell.
- `syntax_parser.md` - Primary Determistic Finite Automaton to parse user command.
- `transition_tool.md` - Provides functionalities for working with DFA-based parsers as in `syntax_parser.md`.
- `utility_box.md` - Provides basic utility functions, mostly related to strings.
