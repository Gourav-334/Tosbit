# 6\) DATA TRANSACTION COMMANDS

## I\) Adding it to stash:
```
add to stash;
```


## II\) Removing from stash:
```
reverse stash;
```


## III\) Committing:
```
commit stash;
```


## IV\) Rollback:
```
@ Rollback 'n' points back @
rollback by 2;
```


## V\) Show Log Records:

### i. Showing all log records:
```
show log;
```

### ii. Show selected number of records:
```
@ showing last 'n' records @
show last 4 log;
```
