# 10\) FILE CONVERTERS

## I\) Javascript Object Notation:

### i. JSON to TOS:
```
make Exam
from json at "path//to//file//filename.json";
```

### ii. DGW to TOS:
```
make json at "path//to//file//filename.json"
from Exam;
```


## II\) Markdown File:

### i. MARKDOWN to TOS:
```
make Exam
from md at "path//to//file//filename.md";
```

### ii. TOS to MARKDOWN:
```
make md at "path//to//file//filename.md"
from Exam;
```


## III\) Tosbit Scripts:

### i. Download script:
```
save script;
```

### ii. Execute script:
```
execute script at "path//to//directory";
```


## IV\) Download logs:

```
save logs;
```
