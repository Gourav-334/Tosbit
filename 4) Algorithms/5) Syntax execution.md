# SYNTAX EXECUTION


## General

- Wait for user to input.
- Analyze
- If problem found:
    - Return error with cause.
- Else:
    - Execute


## Comments

- Until its just space, keep skipping the characters.
- If @ appears, open the comment.


## open db db_name;

- Check if any directory from name db_name exists.
- If exists:
    - Acknowledge that it has been opened.
- If it doesn't exist:
    - Tell that no such database exists.
