# $scripts/$


- `all.sh` - Runs both `compileAll.sh` & `linkAll.sh`.
- `alpinelinux.sh` - Installs all required **development tools** in ***Ubuntu*** & ***Debian***.
- `arch.sh` - Installs all required **development tools** in ***Arch***, ***Manjaro*** & ***EndeavourOS***.
- `compileAll.sh` - **Compiles** all the mentioned source files to object files using **GCC**.
- `fedora.sh` - Installs all required **development tools** in ***Fedora***, ***RHEL***, ***Rocky*** & ***AlmaLinux***.
- `gitter.sh` - Contains personal automation for **dual commit & pushing** of changes (might not be useful).
- `linkAll.sh` - **Links** all the object files compiled through `compileAll.sh`.
- `opensuse.sh` - Installs all required **development tools** in ***OpenSUSE***.
- `remake.sh` - Used for **easy copy** of folders as backup & putting it back after experiment.
- `tosbitAPI.sh` - Creates static library for **driver manager** & related files.
- `ubuntu.sh` - Installs all required **development tools** in ***Ubuntu*** & ***Debian***.
- `voidlinux.sh` - Installs all required **development tools** in ***Void Linux***.
