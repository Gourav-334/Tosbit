# REGULAR EXPRESSIONS

## There are 3 types of states:

- Accept state
- Error state
- Incomplete state


## @ Comment @

```
_*@_*(STRING)_*@_*
```

- (STRING) = Comment
- _ = Space

## open db Office

```
open__*db__*(STRING)_*
```

- (STRING) = Database name
- _ = Space
