# 7\) SELECTION

## I\) Selecting all:

```
show all from table Desk;
```


## II\) Column selection:

```
show column Name from Desk;
show column Name,Dep from Desk;
```


## III\) Conditional selection:

```
show rows from Desk where age<25;
show rows from Desk where age=25;
show rows from Desk where age>25;
```
