# $exec/$


- `backup/` - Contains **backup** for `data/`, `logs/` & `users/` which are originally being used in `build/`.
- `build/` - Main directory for **creating executables** & experimenting with code compiled and linked through **CMake**.
- `CMakeLists.txt` - Contains **CMake script** for target source files which have to be compiled & linked together.
- `remake.sh` - **Copy** of `remake.sh` from `scripts/` at parent directory.
